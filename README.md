# Sistema CRUD - Máquinas Expendedoras

## Descripción del Proyecto

Este proyecto consiste en el desarrollo de una API REST para la gestión de máquinas expendedoras, implementando operaciones CRUD.
La aplicación está desarrollada con:

- Node.js
- Express
- Adminer MySQL
- Bycrypt.js
- Docker

El sistema permite administrar información como:

- Nombre de la máquina
- Login usuario y admin
- Entorno simulado de maquinas
- Ubicación
- Capacidad
- Estado
